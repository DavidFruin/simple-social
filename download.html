Download

Simple Social is available on the web, on your phone, and in your terminal. All of them use the same account, so you can sign in anywhere.

iOS & Android

Add Simple Social to your home screen. It opens full-screen, without the browser's address bar, just like an app from the app store.

If the button doesn't do anything, install it manually instead:

  • Android, Chrome, Edge: open the browser's menu (usually ⋮ or ☰) and tap Install app or Add to Home Screen.
  • iPhone or iPad (Safari): tap the Share icon, then Add to Home Screen.

CLI

A command-line client for scripting and quick one-off commands. Builds from source on Debian and Ubuntu only for now (Arch and Nix support is coming soon).

1. Install the build tools:

sudo apt update && sudo apt install -y build-essential libcurl4 pkg-config

2. Clone the repo, somewhere you own — your home directory is fine:

cd ~ && git clone https://github.com/DavidFruin/simple-social-cli.git

Cloning from / or another root-owned directory fails with could not create work tree dir ... Permission denied. Don't run the clone itself with sudo either — that leaves a root-owned copy that make then can't write to.

3. Build and install it:

cd simple-social-cli && sudo make install

This builds it and copies it to /usr/local/bin/sscli, so you can run it as sscli from anywhere (sudo make uninstall to remove it). If you'd rather not install it system-wide, run cd simple-social-cli && make instead, then use it as ./simple-social-cli --help from inside that folder.

Interactive CLI

A guided command-line client that prompts you for each step. It's a standalone download — you don't need the CLI above unless you want it too. Builds from source on Debian and Ubuntu only for now (Arch and Nix support is coming soon).

1. Install the build tools:

sudo apt update && sudo apt install -y build-essential libcurl4 pkg-config

2. Clone the repo, somewhere you own — your home directory is fine. --recursive also fetches the small library it's built on:

cd ~ && git clone --recursive https://github.com/DavidFruin/simple-social-cli-interactive.git

Cloning from / or another root-owned directory fails with could not create work tree dir ... Permission denied. Don't run the clone itself with sudo either — that leaves a root-owned copy that make then can't write to.

3. Build and install it:

cd simple-social-cli-interactive && sudo make install

This builds it and copies it to /usr/local/bin/sswiz, so you can run it as sswiz from anywhere (sudo make uninstall to remove it). If you'd rather not install it system-wide, run cd simple-social-cli-interactive && make instead, then use it as ./simple-social-cli-interactive from inside that folder.

TUI

A full-screen terminal interface you navigate with the keyboard. It's a standalone download — you don't need the CLI above unless you want it too. Debian and Ubuntu only for now, same as the CLI.

1. Install the build tools and ncurses:

sudo apt update && sudo apt install -y build-essential libncurses-dev libcurl4 pkg-config

If apt update fails because of a broken third-party repository (for example a missing signing key), run the install on its own instead of chained after it — the failed update stops the whole line from ever reaching the install.

2. Clone the repo, somewhere you own — your home directory is fine. --recursive also fetches the small library it's built on:

cd ~ && git clone --recursive https://github.com/DavidFruin/simple-social-tui.git

Cloning from / or another root-owned directory fails with could not create work tree dir ... Permission denied. Don't run the clone itself with sudo either — that leaves a root-owned copy that make then can't write to.

3. Build and install it:

cd simple-social-tui && sudo make install

This builds it and copies it to /usr/local/bin/sstui, so you can run it as sstui from anywhere (sudo make uninstall to remove it). If you'd rather not install it system-wide, run cd simple-social-tui && make instead, then use it as ./simple-social-tui from inside that folder. The first time you run it you'll land on a login screen, where you can log in, register, or reset a forgotten password. Each of the three terminal tools signs in on its own, so logging into one doesn't log you into the others.
